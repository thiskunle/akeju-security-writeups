## Rules for this repository

- Only retired Hack The Box machines and CTFs that have ended. Publishing write-ups for active content breaks platform rules.
- Only authorized targets. Nothing here comes from a client engagement or a real organization.
- Flags and passwords are always redacted. `scripts/check_writeup.py` enforces it.

## Adding a report

1. Copy [TEMPLATE.md](TEMPLATE.md) to `writeups/<platform>-<name>.md`.
2. Write it from your own notes and evidence.
3. Run `python scripts/check_writeup.py`.
